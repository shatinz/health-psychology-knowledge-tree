# سامانه جهان دانش تعاملی و موتور مقایسه بصری اسناد (OmniTree Knowledge Universe)
> **تبدیل هوشمند متون و کتب علمی به درخت دانش چندسطحی، گراف فواصل معنایی و ماتریس تضادهای مفهومی**

این پروژه یک وب‌اپلیکیشن مستقل، مقیاس‌پذیر و ماژولار است که بر اساس محتوای کامل **کتاب مقدمات روانشناسی سلامت (دکتر احمد علی‌پور)** طراحی شده و قابلیت گسترش برای پذیرش و مقایسه هر تعداد کتاب یا فایل PDF دیگر را دارد.

---

## ✨ قابلیت‌های کلیدی سامانه

### ۱. درخت دانش عمیق و بدون حذفیات (Deep Knowledge Tree)
- پیاده‌سازی کامل تمامی ۱۰ فصل کتاب روانشناسی سلامت در چندین سطح عمق (سند ➔ فصل ➔ بخش ➔ نظریه‌ها و پدیده‌ها ➔ مؤلفه‌ها و شواهد بالینی).
- حفظ ۱۰۰٪ کلیه تعاریف، آمارها، اسامی پژوهشگران، مسیرهای فیزیولوژیک، هورمون‌ها و ابزارهای ارزیابی.
- امکان باز و بسته کردن (Expand/Collapse) شاخه‌ها به صورت پویا و انیمیشنی.

### ۲. گراف فواصل معنایی و رمزگذاری بصری شباهت‌ها (Spatial Distance & Similarity Graph)
- **شفافیت خطوط اتصال (Alpha Opacity)**: خطوط میان گره‌ها بر مبنای ضریب همبستگی معنایی ($0.15 \le \alpha \le 0.95$) تنظیم شده‌اند (مفاهیم مشابه‌تر پررنگ‌تر و درخشان‌تر هستند).
- **فاصله فضایی گره‌ها (Spatial Distance Encoding)**: نیروی فیزیکی فنرها برعکس فاصله عمل می‌کند؛ یعنی مفاهیم با بیشترین تقارب به یکدیگر نزدیک‌تر شده و کلاسترهای مفهومی ارگانیک تشکیل می‌دهند.
- **جریان ذرات نورانی سیناپسی (Pulsing Synapse Particles)**: شبیه‌سازی جریان پویای اطلاعات در طول اتصالات قوی.
- **خطوط تضاد جرقه‌ای (⚡ Contrast Edges)**: نمایش آشکار تفاوت‌ها و تقابل‌های نظری (مانند مدل زیستی-طبی در برابر زیستی-روانی-اجتماعی، یا تیپ A در برابر تیپ C).

### ۳. جهان چندسندی و مقایسه ساید‌بای‌ساید اسناد (Multi-Doc Universe & Cross-Doc Diff)
- قابلیت بارگذاری همزمان چندین کتاب یا مقاله (شامل سند مقایسه‌ای پیش‌فرض روانشناسی بالینی و اختلالات روان‌تنی).
- کشف خودکار پل‌های ارتباطی بین دو کتاب مختلف.
- مودال مقایسه‌ای ساید‌بای‌ساید (Side-by-Side Diff) برای مشاهده کلیدواژه‌های مشترک و تمایزات محتوایی.

### ۴. موتور جستجوی بلادرنگ چندمعیاره (Real-Time Search & Filters)
- پشتیبانی از نرمال‌سازی حروف فارسی (ی/ي، ک/ك، نیم‌فاصله).
- فیلتراسیون آنی بر اساس نام دانشمندان (فروید، لازاروس، سلیه، راتر، بندورا، بک، کوباسا و...)، مسیرهای فیزیولوژیک (محور HPA، سلول‌های NK، کورتیزول) و بیماری‌ها.

## 🚀 راهنمای اجرا

این سامانه به صورت کاملاً ایزوله و بدون نیاز به نصب هیچ وابستگی سمت سرور کار می‌کند:

1. کافی است فایل `index.html` را در هر مرورگر مدرنی (Chrome, Edge, Firefox, Safari) باز کنید.
2. برای اجرای محلی روی پورت اختصاصی، می‌توانید از دستور ساده زیر در پایتون استفاده نمایید:
   ```bash
   python -m http.server 8080
   ```
   و سپس به آدرس `http://localhost:8080` بروید.

```
health-psychology-knowledge-tree/
├── index.html                   # بدنه اصلی، لایه‌بندی و ناوبری

│   ├── similarity-engine.js     # محاسبه فواصل فضایی، شفافیت و دیف‌های مفهومی

│   ├── graph-renderer.js        # موتور گراف دوبعدی با فیزیک و ذرات نوری
│   ├── search-engine.js         # موتور جستجوی لحظه‌ای فارسی
│   └── app.js                   # کنترل‌کننده مرکزی رابط کاربری
├── docs/
│   └── doc_schema_template.json # قالب استاندارد JSON برای اضافه کردن هر سند جدید
└── README.md                    # مستندات و راهنما
```

## 📥 افزودن کتاب یا PDF جدید

برای افزودن هر کتاب یا فایل جدید به جهان دانش:
1. ساختار سرفصل‌ها و متون آن را مطابق قالب `docs/doc_schema_template.json` پر کنید.
2. از تب **«مدیریت اسناد»** در برنامه، دکمه **«انتخاب و بارگذاری فایل JSON سند جدید»** را کلیک کنید.
3. سند جدید فوراً به جهان دانش افزوده شده، به درخت اضافه می‌گردد و پیوندهای شباهت و فواصل آن با سایر کتاب‌ها به طور خودکار ترسیم می‌شود.
